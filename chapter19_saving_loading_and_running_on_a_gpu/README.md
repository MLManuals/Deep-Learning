# Chapter 19: Saving, Loading and Running on a GPU

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MLManuals/Deep-Learning/blob/main/chapter19_saving_loading_and_running_on_a_gpu/notebook.ipynb)

This folder holds the code for Chapter 19 of *Deep Learning*, the sixth book in the
[ML Manuals](https://github.com/MLManuals/Deep-Learning) series.

- `notebook.ipynb` -- the chapter's code as a Jupyter notebook, with the same section headings and explanations as the book, ready to open in Colab.
- `script.py` -- the same code as a plain Python script, in case you would rather run it from the command line.

The flower measurements in this chapter are Edgar Anderson's irises, which ship inside scikit-learn, so there is nothing to download, and every random choice uses a fixed seed, so running the notebook from top to bottom reproduces every number in the book exactly.

Every cell runs on a computer without a graphics card. If you have one, the device cell picks it up automatically and the same code runs there.
