# Chapter 17: Convolutional Neural Networks

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MLManuals/Deep-Learning/blob/main/chapter17_convolutional_neural_networks/notebook.ipynb)

This folder holds the code for Chapter 17 of *Deep Learning*, the sixth book in the
[ML Manuals](https://github.com/MLManuals/Deep-Learning) series.

- `notebook.ipynb` -- the chapter's code as a Jupyter notebook, with the same section headings and explanations as the book, ready to open in Colab.
- `script.py` -- the same code as a plain Python script, in case you would rather run it from the command line.

The handwritten digits in this chapter ship inside scikit-learn, so there is nothing to download, and every random choice uses a fixed seed, so running the notebook from top to bottom reproduces every number in the book exactly.

The comparisons in this chapter take under a minute in total to run on a laptop.
