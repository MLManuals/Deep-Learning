# Deep Learning -- Code Companion

This repository holds the code for every chapter of *Deep Learning*, the sixth book in the [ML Manuals](https://github.com/MLManuals) series: neural networks in PyTorch, step by step, from a single artificial neuron to a convolutional network you design, tune, test and explain yourself, every idea explained in plain English before a line of code.

Each chapter gets its own folder with a runnable Jupyter notebook and an equivalent plain Python script, so you can follow along in Colab, in Jupyter, or from the command line.

## What's in each folder

- `notebook.ipynb` -- the chapter's code as a Jupyter notebook, with the same section headings and explanations as the book. Open the Colab badge above and it runs with nothing to install.
- `script.py` -- the same code as a plain Python script, with a comment for each section, in case you would rather run it from the command line.

## Running locally instead of Colab

```
git clone https://github.com/MLManuals/Deep-Learning.git
cd Deep-Learning
pip install -r requirements.txt
jupyter notebook
```

Every chapter runs on an ordinary laptop with no graphics card. Most chapters finish in seconds. Chapters 16 to 18 take under a minute each, Chapter 15 about three minutes and the capstone in Chapter 20 two or three, and each of those chapters says so in its folder. Chapter 19 shows how to move the same code onto a graphics card if you have one.

## Regenerating the data

Nothing in *Deep Learning* is downloaded. Every dataset is either generated in code with a fixed random seed, right there in the chapter that introduces it, or ships inside scikit-learn: the field of plants arranged in rings, the students and their three teachers, the café's cold drinks, the XOR network, the sequences of symbols in Chapter 18, Edgar Anderson's irises from Chapter 11 onwards, and the handwritten digits of Chapters 17 and 20. Running a chapter's own cells rebuilds its data exactly, every time, so every number in the book can be reproduced.

Every chapter is self contained. Where a chapter returns to data or a network from an earlier chapter, it rebuilds them in its own cells, so every notebook here runs on its own from top to bottom.

## About the book

*Deep Learning* assumes everything in *Machine Learning* and *Advanced Machine Learning* and turns to models that build their own features. It builds a neural network by hand first, the neuron, activation functions, loss functions, gradient descent and backpropagation, so that every number is understood, and then shows PyTorch reproducing the same numbers exactly: tensors, autograd, `nn.Module`, the training loop and batching. It goes on to the craft of training networks well, with optimizers, learning rates, regularization, initialization and batch normalization, takes a first look at convolutional networks and sequence models, and closes with saving, loading, running on a GPU and a full capstone project. It is the sixth book in the ML Manuals series, after *Python for Machine Learning*, *Data Analysis with Python*, *Mathematics for Machine Learning*, *Machine Learning* and *Advanced Machine Learning*, and it is followed by *Computer Vision and Multimodal AI*.
