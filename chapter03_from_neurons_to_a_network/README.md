# Chapter 3: From Neurons to a Network

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MLManuals/Deep-Learning/blob/main/chapter03_from_neurons_to_a_network/notebook.ipynb)

This folder holds the code for Chapter 3 of *Deep Learning*, the sixth book in the
[ML Manuals](https://github.com/MLManuals/Deep-Learning) series.

- `notebook.ipynb` -- the chapter's code as a Jupyter notebook, with the same section headings and explanations as the book, ready to open in Colab.
- `script.py` -- the same code as a plain Python script, in case you would rather run it from the command line.

All of the data in this chapter is generated in code, with a fixed random seed, so running the notebook from top to bottom reproduces every number in the book exactly.
